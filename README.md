# satangthevalue-stack-dev
ระบบจำลองสภาวะแวดล้อมเสมือนโปรดักชัน (production-parity) สำหรับการพัฒนาโปรเจกต์บนเครื่อง local แบบครบวงจรด้วย Docker Compose ประกอบด้วย Traefik (HTTPS), PostgreSQL, MinIO, MLflow, Prefect และชุดเครื่องมือ Observability ที่พร้อมใช้งานทันที เหมาะสำหรับการพัฒนาและทดสอบแอปพลิเคชัน AI และ Microservice ที่ซับซ้อน
